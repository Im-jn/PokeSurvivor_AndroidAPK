## 启动修复构建（版本号保持 1.3.2）

安装文件仍为 `dist/PokeSurvivor-1.3.2.apk`，应用名称 PokéSurvivor，系统版本仍为 2.3.2；包名、签名与版本代码保持原值，可以覆盖安装。图标换为用户最新提供的“像素精灵球能量图标.png”。

- 主游戏脚本先完整下载到有大小限制的缓冲区，检查 HTTP 状态、已声明的内容长度和明显的 HTML 错误响应，再交给 WebView 执行；下载错误自动进入本地版。
- 官网主页面网络错误或 HTTP 错误自动进入本地版；另有原生层的 45 秒启动超时检查，即使游戏脚本完全没有执行，也能切换到本地版。已正常进入的在线游戏不会因为这个启动计时器被切走。
- 增强模块与官网主程序分别解析；增强安装失败时只重载一次，使用干净的官网原版文档，不在已被部分替换的游戏对象上继续启动。如果仍无法进入，原生启动超时会转入本地版。
- 缺少 ResizeObserver 时，布局使用其余监听方式；本地字体加载不再无限等待。
- 自动切换本地版后恢复原本的本地存档；没有本地存档则进入本地游客流程。设置中仍可返回官网在线版。官网账号云存档与本地存档分别保存，不自动搬运或合并。
- 本地版所有入口均跳过登录：手动进入离线版、断网回退、直接打开本地页面都自动恢复存档或创建游客存档；本地顶部栏隐藏账号退出入口。

验证：启动恢复的故障注入测试、真实官网增强流程（模拟无 ResizeObserver）、本地自动进入与旧游客存档恢复，以及 APK 签名和结构检查。原生断网回退与计时器已编译并反汇编核对，仍需故障手机复测；不声称已在 Android 真机验证此次修复。
