## 手机界面与图标更新（1.3.1）

安装文件：`dist/PokeSurvivor-1.3.1.apk`，系统显示版本 2.3.1。直接覆盖本项目旧版，保留账号状态和本地存档。

- 登录页改回单列，用户名和密码上下排列；低矮屏幕可滚动表单。
- 顶部栏按实际内容换行，并按实际高度为主菜单与页面留出间距；账号名过长显示省略号，保留完整名称的原数据。
- 主菜单调整间距与触摸区域，同时考虑刘海安全边距。在线与离线模式共用这套布局。
- 应用图标替换为用户提供的“魔法遗迹中的能量捕获球.png”，原图保存在 `artwork/launcher-original.png`，构建时生成五种密度的普通和圆形图标。

已通过真实官网页面的登录表单排列、740×360 / 844×390 / 960×432 / 1280×576 菜单间距检查，以及游客战斗与地图自动暂停验证。使用模拟的长账号名和顶部按钮复现布局，没有更改真实账号或云存档。安装后仍需在手机上确认系统字体缩放、软键盘和桌面图标缓存的表现。
